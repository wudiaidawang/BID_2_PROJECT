# V4.1 召回评测报告（远程 bge-m3 + Milvus + 远程 reranker + 本地 BM25）

**日期**: 2025-06-25  
**Benchmark**: eval_benchmark_v4 (1000 题)  
**Pipeline**: embed-once + 双库并行召回 + RRF 融合 + BGE-Reranker 精排 + source_type boost + 3 题并发评测  
**模型**: embedding: bge-m3 (1024d, 远程 8210) | reranker: bge-reranker-v2-m3 (远程 8210) | Milvus (远程 19531) | BM25: 本地 jieba

## 八、结论

1. **绝对召回率 96.3%，超过 92% 目标**，相比上轮 V4 提升 2.5%
2. **parent_hit@5 达 93.5%**，比上轮 V4 提升 3.5%，来自 BM25 本地化 + Benchmark 修复 + 门控附录检测器 + Milvus 模板清除等改进
3. **Miss 减少 40%** (62→37)，所有类别的 miss 均有下降
4. **pdf_law_child 仍是最大短板** (parent_hit@5=77.0%, miss=15)，child chunk 检索文本短，语义匹配天然劣势
5. **pdf_case_paragraph 首条命中率极低** (19.5%)，但 parent_hit@5 达 97.7%，说明段落检索需要多轮精排才能定位
6. 本次评测采用的 embed-once + 双库并行 + 3 题并发 + BM25 预热方案，在不超载 SSH 隧道的前提下将速度从 ~9s/题 提升至 1.83s/题（4.9x），全程 0 个 502 错误
