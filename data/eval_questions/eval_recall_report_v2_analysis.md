## 2. 检测指标与标准

### 三级命中定义

| 级别 | 条件 | 含义 |
|------|------|------|
| **exact** (精确命中) | retrieved.id == expected.id | 精确匹配到 benchmark 指定的 chunk |
| **parent** (父块命中) | same article_id + law_name + source_type | 未精确匹配，但命中了同一法条的 parent 块 |
| **soft** (软命中) | same article_id + law_name，不同 source_type | 同一条文但来自不同来源（如法条↔案例解读） |
| **miss** (未命中) | 以上均不满足 | 真正未命中 |

### 核心指标

| 指标 | 说明 |
|------|------|
| **parent_hit@5** | Top-5 中至少有一个 parent 或 exact 命中（主指标） |
| **exact_hit@5** | Top-5 中有精确 chunk ID 匹配（数据质量指标） |
| **recall@5 (parent)** | 期望 chunk 中被 parent 级命中的比例 |
| **MRR (parent)** | 首个 parent 级命中排名的倒数均值 |

## 4. Miss 根因分析

101 题 miss 分为四类：

### 4.1 跨法律误匹配（30 题，29.7%）

**根因**：招投标领域存在大量语义重叠的法律法规。同一法律概念（如"中标人确定方式""评标委员会澄清权"）在多部法律中均有规定，但条款号不同。语义向量检索无法区分"国际招标投标活动有关规定第70条"和"招标投标法实施条例第55条"的内容差异。

**典型例子**：

| ID | 问题 | 期望法律·条款 | 实际检索到（top-3） |
|----|------|-------------|-------------------|
| qa_v2_0022 | 国有资金占控股地位的项目中标人怎么确定？ | **国际招标投标活动有关规定#70** | 招标投标法实施条例#55, 勘察设计招标投标办法#40, 施工招标投标办法#58 |
| qa_v2_0024 | 评标委员会什么情况下可让投标人澄清？ | **国际招标投标活动有关规定#64** | 铁路建设工程招标投标#52, 招标采购活动有关规定#32, 施工招标投标办法#51 |
| qa_v2_0032 | 投标人分立什么时候导致投标无效？ | **国际招标投标活动有关规定#44** | 货物服务招标投标管理办法#63, 招标投标法实施条例#38 |
| qa_v2_0039 | 投标截止前提交价格变更声明怎么处理？ | **国际招标投标活动有关规定#40** | 货物服务招标投标管理办法#34(两份), 施工招标投标办法#39(两份) |
| qa_v2_0048 | 招标文件需涵盖哪些基本要求？ | **政府采购货物和服务招标投标管理办法#20** | 施工招标投标办法#14, 通信工程招标投标管理办法#14, 采购招标投标管理办法#18 |

**关键发现**："国际招标投标活动有关规定"（4次miss）"评标委员会和评标方法暂行规定"（5次）"招标投标管理暂行规定"（4次）等综合性法规的内容与其他专项法规高度重叠，是跨法律误匹配的高发区。

### 4.2 同法律错条款号（10 题，9.9%）

**根因**：同一法律内相邻条款语义相近，或问题表述模糊导致检索到相邻但错误的条款。

### 4.3 pdf_case_sliding 滑动窗口无结构化匹配（59 题，58.4%）

**根因**：《招标投标法律解读与风险防范实务》的滑动窗口块没有 article_id 和 law_name 字段，无法使用"父块命中"逻辑。当前只能依赖 exact 匹配（精确 chunk ID），但滑动窗口数量大（2047 个），精确命中率天然受限。

**典型例子**：

| ID | 问题 | 期望 chunk | 检索到（top-3） |
|----|------|-----------|----------------|
| qa_v2_0473 | 两阶段招标里投标保证金什么时候提交？ | pdf_招标投标法律解读与风险防范实务_**144** | 水利监理招标投标管理办法#64, 勘察设计招标投标办法#44, 实务**#1669**（相邻但不同的段落） |
| qa_v2_0474 | 能不能用招标文件没列明的标准评标？ | pdf_招标投标法律解读与风险防范实务_**1272** | 评标暂行规定#17, 公路招标投标管理办法#42, 铁路招标投标#51 |
| qa_v2_0479 | 能不能把注册资本设为资格要求？ | pdf_招标投标法律解读与风险防范实务_**611** | 货物服务招标投标管理办法#17, 实务#762, 实务#612 |
| qa_v2_0480 | 质量体系认证证书过期有什么后果？ | pdf_招标投标法律解读与风险防范实务_**814** | 施工招标投标办法#29, 货物服务招标投标管理办法#23, 实务#846 |

**关键发现**：这类 miss 中，检索结果往往包含了相关法条原文（parent 块），但 benchmark 期望的是案例解读的具体段落。两者语义相关但 chunk ID 不匹配，由于缺少 article_id 无法触发 parent 级命中。

## 5. 改进建议

| 优先级 | 方向 | 预期收益 |
|--------|------|---------|
| P0 | 对 `pdf_case` 类 chunk 增加结构化字段（article_id / law_name），使其被 parent 级召回覆盖 | 59 题 → 预计命中率提升至 70-80% |
| P1 | Reranker 层面引入 law_name 加权：同一法律的候选 chunk 获得 boost，降低跨法律误匹配 | 30 题跨法律 → 预计减少 50% |
| P2 | 查询层面增强法律名识别：当问题明确引用某法律时，增加该法律的检索权重 | 10 题同法律错条号 → 预计减少 30-40% |
